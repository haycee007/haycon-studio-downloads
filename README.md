# HayCon Studio downloads

[Open HayCon Studio in your browser](https://haycon-studio.vercel.app/) · [Download the Windows installer](https://github.com/haycee007/haycon-studio-downloads/releases/download/windows-v27.1.0/HayCon-Studio-Setup-27.1.0-x64.exe)

## Install on Windows

1. Download the setup EXE from the link above.
2. Open it from your browser's Downloads.
3. Follow setup, then open **HayCon Studio** from the Start menu.

Supports 64-bit Windows 10 and later. Setup installs for your Windows account, with an optional desktop shortcut. If Microsoft's WebView2 component is missing, setup downloads and installs it. Online features need an internet connection.

The installer is not code-signed. Windows may show an unknown-publisher warning. The release includes SHA256SUMS.txt and windows-installer.json so you can verify the exact file.

Uninstall through **Settings → Apps → Installed apps → HayCon Studio**. Saved music and recordings are kept separately and remain after uninstalling. Website and desktop libraries are separate; download a transcription backup to move notes between them.

## Phones and tablets

Open the web app, then use your browser's **Install app** or **Add to Home Screen** option. The Windows installer is for Windows computers.

This repository hosts installer downloads and checksums. Third-party license notices and FFmpeg source/build links accompany the installed app.
